## 🎮 Steam Auto Launcher

Простой и надёжный лаунчер для запуска Steam и игр на несколько аккаунтов.

### 🚀 Возможности

- ✅ Запуск Steam (только Steam)
- ✅ Запуск Steam + игра через App ID
- ✅ Запуск Steam + игра через прямой путь к exe
- ✅ Автоматический обход диалога "Кто играет?"
- ✅ Безопасное хранение паролей (зашифрованы)
- ✅ GUI для управления аккаунтами
- ✅ Настраиваемые задержки
- ✅ Логирование всех действий

### 📋 Требования

- **Python 3.8+**
- **Windows 10/11**
- **Установленный Steam**

### 📦 Установка

```bash
git clone https://github.com/almostbot777-droid/test.git
cd test
pip install -r requirements.txt
python main.py
```

### ⚙️ Первый запуск

1. Запусти `python main.py`
2. На первый запуск создастся `config.json` с пустыми аккаунтами
3. Нажми **Добавить аккаунт**
4. Заполни:
   - **Название**: любое (для вас)
   - **Steam логин**: твой Steam аккаунт
   - **Пароль**: пароль (будет зашифрован)
5. Нажми **Сохранить**
6. В настройках укажи путь к `steam.exe` и параметры игры
7. Выбери аккаунты и нажми **Запустить**

### 🎯 Использование

**Вкладка "Аккаунты":**
- Выбери один или несколько аккаунтов (чекбоксы)
- **Выбрать все** / **Снять все**
- **Добавить** / **Удалить** аккаунт

**Вкладка "Настройки":**
- Путь к `steam.exe`
- Путь к exe игры или App ID
- Задержки для синхронизации

**Запуск:**
- **▶ Только Steam** — просто запустить Steam
- **▶ Steam + Игра** — запустить Steam и игру
- **⏹ Стоп** — остановить процесс

### 🔐 Безопасность

- Пароли шифруются на диске (используется `cryptography`)
- Ключ шифрования хранится локально
- Данные не отправляются никуда
- Используй только на своём ПК

### ❓ Проблемы

**"Диалог 'Кто играет?' не обходится"**
- Увеличь "Задержка загрузки Steam" (с 15 на 20-25)
- Увеличь "Задержка обхода диалога" (с 3 на 5-7)

**"steam.exe не найден"**
- Укажи путь вручную: `C:\Program Files (x86)\Steam\steam.exe`

**"Игра не запускается"**
- Проверь правильность App ID или пути к exe
- Убедись что игра установлена через Steam
